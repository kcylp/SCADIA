# MES / EMS 工程模板

一句话介绍：一套**可直接导入 SCADIA** 的 MES（制造执行）/ EMS（能源管理）工程模板，含 5 个画面、10 个导航入口、30 个 tag、3 个脚本、3 条报警、2 份报表与 1 个配方模板，演示数据全部是固定常量（零随机数），导入即可看到完整看板，再按手册替换成现场数据源。

- **快速开始**：见 [MES-EMS-开发手册.md](./MES-EMS-开发手册.md) 第 1 章「快速开始（5 分钟）」
- **二次开发 5 步**：见 [MES-EMS-开发手册.md](./MES-EMS-开发手册.md) 第 5 章
- **脚本 API 参考**：见 [MES-EMS-开发手册.md](./MES-EMS-开发手册.md) 第 6 章
- **验收标准与可复现校验命令**：见 [MES-EMS-开发手册.md](./MES-EMS-开发手册.md) 第 7 章
- **与规格书的偏差说明（请复核）**：见 [MES-EMS-开发手册.md](./MES-EMS-开发手册.md) 附录 A

## 文件清单

| 文件 | 说明 |
|------|------|
| `mes-ems-template.scadiap` | 工程文件本体，UTF-8 **带 BOM**（首字节 `EF BB BF`），2 空格缩进 |
| `MES-EMS-开发手册.md` | 开发手册：快速开始 / 结构总览 / 数据层 / 画面组态 / 二次开发 5 步 / 脚本 API / 验收标准 |
| `README.md` | 本文件 |

## 导入方式

SCADIA 控制台首页（`#/home`）→ 顶部标题栏左侧「打开项目」→ 选中 `mes-ems-template.scadiap` → 打开 → **F5** 刷新。详细步骤与失败排查见手册 §1.2。

> 本模板**不修改任何 SCADIA 源码**、不新建后端域、不新建 API、不新建存储表；纯工程配置 + 脚本，可复制分发。
