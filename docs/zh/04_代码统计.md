## 6. 复现方式

统计脚本是一次性的 Node 脚本（遍历目录、按扩展名计数、按前缀分类 vendored）。复现要点：

1. 目录遍历时排除 `node_modules` / `dist` / `.angular` / `.cache` / `coverage`；
2. 扩展名排除 `.map .log .png .jpg .gif .ico .ttf .woff .woff2 .eot .icns .db .scadiap`；
3. vendored 判定前缀：`client/src/assets/lib/`、`client/src/assets/fonts/`、`client/src/assets/images/`、`client/i18n-parked/`、`node-red/`、`server/integrations/node-red/`、`server/_assets/`、`*package-lock.json`。
