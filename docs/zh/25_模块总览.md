**AI 视频接入的完整链路**【实测 + 引用设计文档】：
① 外部分析引擎（用户自建，Frigate/PaddleDetection 那类）订阅 **RTSP** →
② 检测结果推到 **MQTT / WebSocket / HTTP** →
③ 平台 `ai-service` 收下、`normalize` 归一化、按 `minScore`/`labels`/`ttlMs` 过滤 →
④ `/video` 上**叠加检测框** →
⑤ 命中时 `raiseAlarm` → `cameraFusion.writeEvent(alarmTagId, 1)` → **变成 SCADIA 报警标签** → 走报警域。
配置项：`minScore` `labels` `ttlMs` `maxDetections` `detectWidth/Height` `alarmTagId` `alarmClearMs` `cameraMap`。
**模拟脚本**：`server/scripts/ai-simulate-detections.js`（另有 `gb28181-simulate-device.js`）——**可以直接拿来验证这条链路**。
