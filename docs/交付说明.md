## 4. 怎么把程序跑起来（最快路径）

> ⚠️ 本节命令里的 `source/` 是**那个交付包**的目录名。在本仓库里对应的就是仓库根：`cd server`（不是 `cd source/server`），工程示例见 `examples/`。


前置：安装 **Node.js 18/20**（本机用的是 20.18.0）。

```bash
# 1) 装依赖（source 里未附带 node_modules，需自行安装）
cd source/server   && npm install
cd ../client       && npm install

# 2) 构建前端（改过 client 后必须做；产物 client/dist 由服务端自动服务）
cd ../client       && npm run build

# 3) 启动服务端（工作目录必须是 server）
cd ../server       && npm start        # 等价于 node main.js
```

然后浏览器打开 **http://127.0.0.1:1881/** 。

### 用哪套工程数据？

- `project/` 就是**当前正在跑的工程**。把它的内容放到 `source/server/_appdata`、`_db`、`_images` 下再启动，即用此工程：
  ```bash
  cp -r project/_appdata  source/server/_appdata
  cp -r project/_db       source/server/_db
  cp -r project/_images   source/server/_images
  ```
- 或换个工程：替换 `server/_appdata/project.scadiap.db` 等即可（工程=数据，见手册 §7）。

## 5. 端口与默认地址

| 端口 | 用途 |
|---|---|
| **1881** | 网页 + REST API + Socket.IO（主入口） |
| 1890 | AI 视频分析 WebSocket |
| 4840 | OPC UA Server：`opc.tcp://<ip>:4840/UA/SCADA` |
| 5060 | GB28181 SIP（UDP） |

配置在 `server/_appdata/settings.js`。

## 6. 本次交付特别说明（重要）

- **不含 `node_modules`、`.git`、`client/dist`**：依赖与构建产物体积大且可再生，按第 4 节自行 `npm install` / `npm run build` 即可。
- **不含 `docs/images`**（SCADIA 原版文档配图，34MB，与本工程无关）。
- `project/_images/zc/` 是为「展厅」画面准备的背景图与图库（HTTP 路径 `/_images/zc/...`）。
- `04_展厅产物/` 是展厅工程的**证据链**：`decrypted/`（解密出的明文画面 XML）、`views/`（转换后的平台 view JSON）、`render/`（渲染截图与校色图）。

## 7. 常见问题（3 条）

1. **改了前端没生效？** 前端是构建产物：必须 `npm run build`（或在 `client` 下 `ng build`），再刷新浏览器。
2. **数据不刷新？** 看设备是否启用/在线、驱动地址与轮询周期，日志在 `server/_logs/scadia.log`。
3. **想改端口/开写权限？** 改 `server/_appdata/settings.js`（写操作需 `secureEnabled=true`）。
