# 契约 02 · Tag 身份与绑定生命周期契约 v1

> 状态：**草案**（待批准生效）｜ 覆盖意见：Codex 2、5 ｜ 台账：L-05、L-10、L-17
> 证据：`07_证据登记册.md` E01-E14、E37 ｜ 日期：2026-09-29

## 1. 目的

把架构原文 L120／L140 的**过强等号**（"tagId 不变 → 全部消费者零改动"）替换为**可验证的义务集合**。
评审原文 L120 同时要求：**明示切换过程中允许的数据间断**，不得用"零改动"暗示"零间断"。

## 2. 术语分层（本契约的核心修正）

评审原文 L253-256 要求"分别定义 Tag 身份、通信绑定、界面分组"。本契约采用三分：

| 概念 | 定义 | 稳定性要求 |
|---|---|---|
| **Tag 身份（tagId）** | 测点的**长期引用锚点** | **不可变**、全局唯一、删除后不复用 |
| **通信绑定（binding）** | 该 Tag 当前**从哪里取值/写值**（设备、通道、地址、驱动） | **可变**，每次变更产生**新代际** |
| **界面分组（channel 分组）** | 组态界面上的归类展示 | 可变，**不影响数据语义** |

**推论（回应意见 5）**：通道若承载连接地址/串口参数/认证/超时/轮询周期，它属于**通信绑定**，必须有独立配置与生命周期；**不能**因为"Tag 只保存一个 `channelId` 属性"就把连接职责散落到各 Tag。

## 3. 现状（实测）

| 事实 | 证据 |
|---|---|
| 结构确为 `device.channels` + 扁平 `device.tags[tagId]` | `channel-utils.js:8-22` |
| **无**独立于设备容器的 Tag 查找 | `devices/index.js:398-405` 遍历设备取首个命中（O(n)，重复 id 结果不确定） |
| **无**绑定代际标识 | 全库无 `bindingRevision` |
| OPC UA 身份**不稳定** | `opcua-server/index.js:115-121,305-307`：`ns=<运行时索引>;s=<含设备名+Tag名的路径>` |
| Tag 导入只增不删、不静默覆盖 | `tag-io.js:8-15`（**正面资产**） |
| 删除通道默认回落到默认通道 | `channel-utils.js:326-351` |

## 4. 规范性要求

### 4.1 tagId 身份（MUST）
1. tagId MUST 在**工程范围内全局唯一**；实现 MUST 提供可执行的唯一性校验（导入、复制设备、批量生成时均执行）。
2. tagId MUST NOT 因设备/通道改名而改变。
3. tagId MUST NOT 被复用：删除后 MUST 进入**不可再用**状态（保留墓碑记录），或在生成时保证单调不复用。
4. tagId 的**生成规则** MUST 文档化（字符集、长度上限、大小写敏感性、导入冲突消解策略）。
5. 导入冲突 MUST 显式报告（沿用 `tag-io.js` 既有"跳过并报告"语义），MUST NOT 静默覆盖。

### 4.2 独立 Tag 访问接口（MUST）
1. MUST 提供**不依赖父设备容器**的 Tag 解析接口，例如 `resolveTag(tagId) → { deviceId, channelId, tag, bindingRevision }`。
2. 实现 MUST 使用**索引**（tagId → 位置），MUST NOT 依赖遍历设备树；解析应为 O(1) 或 O(log n)。
3. 当 tagId 出现于多个设备时，解析 MUST **报错并指出冲突**，MUST NOT 静默取首个命中。
4. 过渡期：既有 `getDeviceIdFromTag` MUST 改为基于索引，并保留其对外语义（返回 deviceId）。

### 4.3 绑定代际（bindingRevision）（MUST）
1. 每个 Tag 的通信绑定 MUST 携带**单调递增的代际标识** `bindingRevision`。
2. 绑定的**原子发布**：变更（换设备/换通道/换地址/换驱动）MUST 一次性发布新的 `bindingRevision`；进行中的**旧绑定回调 MUST 被丢弃**（校验代际不一致即丢弃）。
3. **待执行写命令 MUST 绑定目标代际**：重连或换绑后，属于旧代际的写命令 MUST NOT 投递到新目标。
4. 代际变更 MUST 记录审计（何时、由谁、从哪个绑定到哪个绑定），并可查询。
5. **数据间断必须可解释**：换绑期间允许的间断时长 MUST 有上限并可配置；超限 MUST 告警，MUST NOT 静默。

### 4.4 语义稳定（MUST）
1. Tag MUST 携带并随数据一起提供：**数据类型、工程单位、质量码、时间戳、标定版本**。
2. 以下变更 MUST 走**显式语义迁移**流程（不得仅保留原 tagId 了事）：
   - 更换传感器 → 必须**重新确认量程/单位/标定**，并产生**新的标定版本**；旧数据 MUST 继续用**旧版本**解释。
   - 量纲改变（温度点→压力点）→ MUST **新建测点身份**或执行显式迁移（记录迁移映射）。
3. 历史数据 MUST 能回答"该点在当时使用哪一版单位与标定"。实现方式（建议）：历史记录或分段元数据携带 `unitVersion`/`calVersion`；至少 MUST 有**变更时间线**可回溯。

### 4.5 OPC UA 外部身份（MUST）
1. NodeId MUST 由**稳定标识**构成，MUST NOT 使用可变的设备名/Tag 名/通道名作为身份。
2. MUST 区分 **命名空间 URI（稳定）** 与 **命名空间索引（每次连接可变）**；对外发布的身份 MUST 基于 URI 语义，不得把运行时索引当作长期身份。
3. 展示用浏览路径（`SCADA/Devices/…`）可以含名称，但 MUST 与**身份**分离：改名 MUST 只影响 BrowseName/DisplayName，MUST NOT 改变 NodeId。
4. 发布 MUST 保证：设备/Tag 改名后，既有客户端订阅**不失效**。

### 4.6 通道语义（MUST）
1. 配置继承 MUST 明确优先级（建议：Tag > 通道 > 设备 > 全局默认），并 MUST 在界面上可见。
2. **删除通道** MUST 显式询问去向，MUST NOT 静默回落；受影响 Tag 清单 MUST 在操作前展示。
3. 无通道的老工程 MUST 明确语义（现状：隐式默认通道 `''`，仅派生不落盘，见 `channel-utils.js:19-21`）——该语义 MUST 写入手册。
4. **虚拟/计算/AI 预测 Tag** MUST 有明确的来源类型（不是物理设备），MUST NOT 被迫伪装为物理 Tag。
5. 通道切换 MUST 通过**统一绑定操作**完成，各驱动 MUST NOT 各自修改工程 JSON（呼应评审原文 L259）。

## 5. 验收门禁

| 门禁 | 方法 | 通过条件 |
|---|---|---|
| **G-TAG-1 消费者零配置改动** | 跨设备移动一个 Tag（tagId 不变） | 报警规则/报警历史/趋势/报表/配方/脚本/标定/调度/实时图表/OPC UA 订阅 **均不需改配置**（逐项验证 11 类消费者） |
| **G-TAG-2 外部身份稳定** | 移动/改名后重连 OPC UA 客户端 | NodeId 不变；既有订阅仍有效 |
| **G-TAG-3 无重复 id** | 构造两设备含同一 tagId 的工程 | 导入被拒绝或显式报告冲突；**不得**静默取首个 |
| **G-TAG-4 旧绑定不覆盖** | 模拟"从 A 切到 B，A 的旧请求延迟返回" | B 的新值**不被**A 的旧值覆盖 |
| **G-TAG-5 写命令不误投** | 重连/换绑瞬间下发写命令 | 旧代际命令被拒绝，不投给新设备 |
| **G-TAG-6 语义迁移** | 换传感器/改量纲 | 产生新标定/新身份；历史仍按旧版本解释 |
| **G-TAG-7 死区与报警** | 99→101、死区 10、阈值 100 | 报警**必须**触发（当前实现存在漏报路径，见 E01-E05 / 台账 L-10） |
| **G-TAG-8 删除通道** | 删除仍有 Tag 的通道 | 必须显式确认去向，不得静默回落 |

## 6. 待定问题

| # | 问题 | 处置 |
|---|---|---|
| Q1 | `bindingRevision` 是否需要持久化（重启后保持） | 建议**持久化**，否则重启即失去代际区分 |
| Q2 | 索引的构建时机与规模 | 需现场 Tag 规模（1000/10000 级）压测后定 |
| Q3 | 墓碑（不复用）是否需要一个独立存储 | 建议放工程库；避免垃圾回收导致 id 复用 |
| Q4 | 跨设备移动是否需要"两步确认"（裁决项 D5） | 待老板裁决 |

## 7. 明确不做

- 不做与设备容器无关的**全新数据模型**（tagId 仍是唯一锚点，呼应架构原文 L165）。
- 不改变既有 `device.tags[tagId]` 存储形态（兼容老工程）。
- 本契约**不构成改码授权**。
