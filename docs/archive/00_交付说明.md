# 开诚智枢 SCADIA · 交付说明（00）

> **一句话定位**：开诚智枢 SCADIA 是一套开箱即用的 Web 组态 SCADA/HMI 平台（浏览器看画面、看数据、下命令），基于开源 SCADIA（MIT）二次开发，内置视频/GB28181 接入、OPC UA Server、Node-RED 工作流与行业演示工程。本交付包**自包含**：源代码 + 已装依赖 + 已构建前端 + 正在运行的工程数据，到手即可启动。

- 版本：`@kcylp/scadia-server` / `@kcylp/scadia-client` 均为 **1.0.0**（见各自 package.json）
- 环境：Node.js 18+（交付机为 Node 24）；启动脚本需 **PowerShell 7（pwsh）**
- 包内已含 `node_modules`（server 约 240MB / client 约 445MB）与 `client/dist`（约 76MB）：**无需 npm install、无需手工构建**

## 1. 快速开始（三步内跑起来）

在**包根目录**用 PowerShell 7 执行：

```powershell
cd '开诚智枢 · Kaicheng SCADIA'
.\start-scadia.ps1        # 检查依赖 → dist 缺失时自动构建 → 以 --userDir project 启动，端口 1881
```

浏览器打开 **http://127.0.0.1:1881/** 即可。

- 检查 server 依赖与 `client/dist`，dist 缺失时自动 `npx ng build`（`-Rebuild` 可强制重建）
- 以 `node main.js --port 1881 --userDir <包>\project` 启动，**直接使用 project/ 工程数据，无需复制**
- 可选参数：`-Sandbox`（复制工程到临时目录运行、不写 project/）、`-Port 1882`（换端口）

> ⚠️ 启停/重启**一律用本脚本**，不要 `npm start`（原因见「常见问题」第 2 条）。

## 5. Node-RED 说明

- 已启用（`nodeRedEnabled: true`）；编辑器挂在 **/nodered/**，界面为**简体中文**（`editorTheme.language: 'zh-CN'`）
- 访问模式 `nodeRedAuthMode: "legacy-open"`：**无独立登录**，与交付包 `secureEnabled=false` 的整体姿态一致
- 要收紧：把 `nodeRedAuthMode` 改为 **"secure"**（settings.js / mysettings.json 或系统设置页），编辑器将要求登录
- Dashboard 等输出节点挂载在 **/dashboard**；应用内「工作流」菜单（/flows）用于管理流程

## 9. 常见问题

1. **GB28181 实时播放失败（MEDIA_NOT_CONFIGURED）？** 国标点流依赖 **ZLMediaKit 流媒体网关**（浏览器不能直连 RTSP）：在 `settings.js` 的 `mediaServer` 中 `enabled: true` 并填写 apiUrl / secret / publicHost。未配置时点流返回 `MEDIA_NOT_CONFIGURED`，属预期行为而非故障。
2. **重启不要用 `npm start`。** 不带 `--userDir` 启动会把数据目录解析到 `source/server/_appdata`，读不到 project/ 工程；旧文档的 `cp -r project/_appdata source/server/` 更会嵌套成 `_appdata/_appdata`。统一用 `.\start-scadia.ps1`。
3. **改了前端没生效？** 前端是构建产物：在 `source/client` 下 `npx ng build`，或 `.\start-scadia.ps1 -Rebuild`，再刷新浏览器。
4. **数据不刷新 / 设备掉线？** 查设备启用状态、驱动地址与轮询周期；日志在 `project/_logs/`。
5. **想换端口 / 开安全？** `-Port 1882` 换端口；`secureEnabled`、`nodeRedAuthMode` 等改 `project/_appdata/settings.js`（或 mysettings.json）后重启。
