## 1. 本窗口完成的四块（均已验收）

### 1.1 分辨率自适应 —— 大屏/多屏/笔记本

**根因**：唯一入口要求 `hmi.layout.zoom === 'autoresize'`，而该工程 `hmi.layout` **不存在**
→ 条件恒假 → **从未执行过一次缩放**。实测：1770×993 画布在 1493×933 视口下**右裁 277px、底裁 110px**。

**交付**：
- `Utils.fitView()` 统一缩放引擎（contain/cover/stretch/width/none）
- 触发源全覆盖：ResizeObserver + resize + 方向 + 全屏 + 可见性 + **DPR 变化**
- `?kiosk=1` 大屏模式（隐藏顶栏/光标/滚动条）
- UI 缩放：≤2560 不变、3840→1.25、5760→1.5（顶栏/菜单同步）

**验收**：CDP 矩阵 **10/10**（含 2240×1400@150% / 4K / 5760×1080 / 1080×1920 竖屏）。

### 1.2 品牌清零

改名编辑器包/图标/截图；`brandingGuard` 扩充为 5 条规则 + **行级豁免 + 文件名扫描**。
**8/8 通过**，构建产物中旧品牌字样 **0 处**。

### 1.3 多语言体系（中/英/俄）

**根因（很重要）**：`assets/i18n/*.json` **混了两种结构**（扁平 `"dlg.cancel"` + 嵌套 `"dlg": {...}`），
而 ngx-translate 默认解析器**只走嵌套路径** → 一旦某命名空间存在对象，**它下面所有扁平键全部失联**
→ 整屏显示 `dlg.setup-title` 这类原始键名。**实测**：`translations['zh-cn']` 有该键，`instant()` 返回键名。

**交付**：
- `FlatTranslateParser`：**先扁平、后嵌套**（严格增量，零冲突实测）
- 语言收敛为 `zh-cn / en / ru`，**其余 12 个移出构建** → `client/i18n-parked/`（可随时移回）
- `SHIPPED_APP_LANGUAGES` 单一事实来源（选择器/加载器/测试共用），旧设置自动夹回
- **统一语言开关**：一处切换同时驱动「界面外壳」与「画面内容」
- **内容词典（方案 B）**：中文原文当键，`content-seed.ts` + 渲染期替换（含**不覆盖实时值**与**无损往返**护栏）
- 格式层：`SHIPPED_LOCALE_FORMATS`（时间/日期/小数分隔符跟随语言）

**验收**：`i18nCoverage` 9/9 · `i18nResolution` 5/5 · `contentDictionary` 7/7 · `contentWiring` 7/7。
真机实测：切英/俄后**整个 DOM 中文残留 = 0**，切回中文**完整还原**。

### 1.4 报表根基

- **契约单一来源** `runtime/reporting/contract.js` + `contract.test.js` **6/6**
  → 修平 3 处真实漂移（客户端少 `班次/季度/年度`；`one` vs `none`；服务端字面量无声明）
  → **未知取值不再静默退化成"实时"**（改为报错 —— 这是最危险的静默错误）
- **时段引擎** `runtime/reporting/period.js` + `period.test.js` **35/35**
  → 生产日可设点（默认 08:00）、三班、**夜班归前一生产日的最后一班**、任意时段/季/年/滚动
  → **发现并修复夏令时缺陷**：按毫秒平移 7×24h 跨 DST 会错 1 小时（英语区客户会踩）
  → 回归测试**钉死时区**（`TZ=America/New_York` 起子进程），中国机器上也会失败
- **中文 PDF 字体缺陷（严重，已修）**
  → 实测 Roboto **CJK 字形 0 个**（西里尔有）→ **中文报表抬头与内容一直是空白，静默无日志**
  → `font-coverage.js` 按语言选字体（zh-cn→SimHei；en/ru→Roboto）+ 缺失时**明确告警**
  → `reportFonts.test.js` **8/8**，含**真实生成 PDF 并断言嵌入 CJK 字体**
- 新增只读接口 `GET /api/report-period`；客户端那份**重复的时段计算已删除**，改为向服务端取

## 2. 已拍裁决（**新窗口必须遵守，不得重新讨论**）

| # | 裁决 |
|---|---|
| 1 | **语音不参与控制 —— 红线**。只读查询/导航/播报；控制类意图一律拒绝并记审计 |
| 2 | 内容多语言走**方案 B**（中文原文当键，零改造），`@key` 保留为高优先级 |
| 3 | 报警/事件历史存 **「码 + 中文原文快照 + 生成时语言」**，**绝不存译文** |
| 4 | 报表语言**三级**：跟随查看者 → 报表固定 → 跟随收件人 |
| 5 | 其他语种：**选择器隐藏**（文件保留，不删） |
| 6 | 英/俄区**录音不留存**（只存文本转写 + 审计） |
| 7 | 生产日**可设点**；**三班**；**夜班归前一生产日最后一班**（日产 = 三班之和） |
| 8 | 报表要 **Excel（原生图表）+ PDF 打印**；行列间距可调；自动列数提示；小数位默认 2（标签格式优先） |
| 9 | **Excel 图表必须原生可编辑**——已实测验证：ExcelJS 4.4.0 与 excel4node **都没有图表实现**，方案是自己注入 OOXML 部件（已跑通并验证） |
| 10 | 配色：报表白底 vs 应用深色**严格区分**；系列色对比度 ≥4.5:1；**黑白可辨（颜色+形状双编码）** |
| 11 | **产品边界：不拆软件，拆工作台**（一个内核 + 运行态/工程态分离 + 角色化工作台 + 功能开关授权） |
| 12 | **数据库**：默认 SQLite（零运维）+ PostgreSQL（标准/信创基线）+ TDengine（时序）；信创走 **PG 系 / 达梦 Oracle 系 / MySQL 系**三个适配器 |
| 13 | **三条铁律**：① 架构守护测试**先行** ② 接口冻结前做**纸上实现** ③ **填空失败就修接口，不打补丁** |
| 14 | **预留位置，而非现在实现**：CPU 架构 / Node 原生模块 / 数据库 / 设备生态 —— 留"缝"，不留 TODO |

**附带裁决**：**D6 已确认 —— 品牌数据库迁移（`.fuxap.db → .scadiap.db`）从未实现。**
