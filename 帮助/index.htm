开诚智枢 SCADIA 使用手册

版本 1.0.0 ｜ Web 组态式 SCADA/HMI 平台 ｜ 18 个模块章节，均含当前交付版真实截图

快速开始（三步跑起来）

  1. 双击安装包完成安装（或解压压缩包到任意目录）。
  2. 运行目录下的 启动 SCADIA（start-scadia.ps1 / 快捷方式）：服务会在本机 1881 端口启动，浏览器自动打开。
  3. 默认账号 admin / 123456（安全开关默认关闭，通常免登录）；首次使用建议先看本手册各模块章节。

端口与端点

  • 1881：Web 界面与 API
  • /nodered/：Node-RED 流程编辑器（简体中文）
  • /dashboard：Node-RED 仪表盘
  • /_help：本手册的网页版（应用内“使用手册”按钮打开）
  • 4840：OPC UA 服务器

找不到答案时

  • 界面右上角的“使用手册”图标随时打开本手册。
  • 运行日志在工程目录 project/_logs/，界面“系统 → 日志”也能看（只显示尾部，防卡）。
  • 安全关闭时，设备写值与标定应用会被平台拒绝（返回 403），这是既定姿态；需要写入请启用安全并登录管理员。
