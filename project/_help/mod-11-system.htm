11. 系统与设置

入口：左侧菜单「系统」 · 路由 /users（用户管理） · 设备 / 脚本 / 通知 / API 密钥 / 插件等页经由系统页顶部的「设置」对话框进入

功能概述

「系统」菜单进入用户管理页（/users），这也是全部系统管理页的枢纽：系统类页面顶部有保存（项目菜单）与设置两个按钮，点「设置」打开分组卡片式导航对话框，可跳转到设备与标签、脚本、通知、API 密钥、插件、角色、报表、标定、视频监控、Node-RED 流程、日志等所有管理页。首页右上角的演示工程按钮也在本章说明。

④ 用户编辑对话框字段：用户名、全名、密码、授权组（查看器/操作员/工程师/监督员/经理等，空=对所有人授权）、角色、语言、起始视图。

各系统页要点

页面说明
设备与标签设备列表（名称/地址/类型/轮询），支持 OPC UA、S7、Modbus、BACnet、Ethernet/IP、三菱 MELSEC、倍福 ADS、Redis、WebAPI、WebSocket、MQTT、GPIO 等类型；点「编辑设备标签」逐个配置 Tag（名称/地址/类型/最小/最大/单位等）。
脚本脚本列表 + 脚本编辑器：编写 JavaScript，可设参数、运行模式（客户端/服务端）、权限与调度（按间隔或计划执行）。
通知通知设置列表：名称、接收者、延迟（分钟）、间隔（分钟）、类型（警报/触发/访问-登录注销）、已启用；模式可选「通知所有新激活的报警」或「按优先级通知一条」。
API 密钥为第三方系统签发访问密钥。
插件管理已安装的平台插件。

逐步操作

新建一个值班账号

  1. 点击左侧菜单「系统」进入 /users。
  2. 点左上 +（或右下角悬浮 +）打开用户编辑对话框。
  3. 填写用户名（如 zhiban01）、全名、初始密码。
  4. 「授权组/角色」选择「操作员」；「起始视图」选择希望该用户登录后看到的画面。
  5. 保存后列表出现新行；用该账号登录即受角色权限约束。

从系统页跳到设备配置

  1. 在 /users 页顶部点设置（齿轮）按钮，弹出设置对话框。
  2. 在「杂项」组点「连接」卡片，进入设备与标签页。
  3. 点「添加设备」选择设备类型（如 OPC UA），填地址 opc.tcp://[服务器]:[端口]，保存后即可添加标签。
  4. 配置完成后点顶部保存按钮（磁盘图标）保存项目，防止丢失。

切换演示工程

  1. 回到「首页」。
  2. 点击页眉右侧演示工程按钮（dynamic_feed 图标）。
  3. 菜单中选择「矿区演示工程」或「出厂演示工程」。
  4. 整套画面、设备与演示数据立即切换；左侧菜单与功能入口保持不变。

修改界面语言

  1. 设置对话框 → 「语言」卡片，进入语言文本列表页。
  2. 平台已内置简体中文（zh-cn）等语言包，按需调整文本后保存。

提示与常见问题

  • admin 账号能删吗？ 不能，内置管理员受保护；可为日常值守另建账号。
  • 系统页顶部多了「保存」「设置」按钮？ 这是系统类页面的固定页眉：磁盘图标是项目菜单（新建/保存/另存为/打开/重命名项目），齿轮打开设置对话框。
  • 改了设备/脚本没生效？ 系统页的修改需点顶部「保存」按钮保存项目；部分设置（如 Node-RED 访问模式）需重启服务端后生效。
  • 切换演示工程后我的修改还在吗？ 演示切换会加载所选演示工程的完整数据，之前对当前工程的未保存修改请先保存。
  • 忘记密码？ 默认账号 admin / 123456；安全模式默认关闭，通常无需登录即可操作。
