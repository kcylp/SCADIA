一、安装与启动

1. 环境要求

组件必需性没有会怎样
Windows 10/11必需—
Node.js 18+克隆 GitHub 后必需（npm install）装不了服务端依赖；整包拷贝版自带 runtime/node 可免
ffmpeg（PATH）推荐视频回落抓拍模式，约 1 帧/秒
Python 3.10+ + ultralytics + opencv-python可选无人体框/轨迹，其余正常
海康相机（ISAPI，演示地址 192.168.110.21）可选无实时画面与四类智能事件

2. 五步启动

git clone https://github.com/kcylp/SCADIA.git
cd SCADIA/source/server && npm install
cd ../..
powershell -ExecutionPolicy Bypass -File .\start-scadia.ps1
浏览器打开 http://127.0.0.1:1881（admin / 123456）

整包拷贝版（含 node_modules）跳过 npm install，直接第 3 步。

3. 四个后台进程

进程职责挂掉的现象
服务端 :1881平台本体：API/画面/报警/SQLite/OPC UA/Node-RED页面打不开
MJPEG 代理 :1886ffmpeg 拉 RTSP，广播给各视频窗；/stats 看状态视频窗黑，10 秒内自愈
事件桥接器相机 alertStream 到平台报警/计数/围栏/抓拍四类事件不再上报
AI 追踪器YOLOv8 推理出人员框与轨迹画面无人体框
重启后打不开页面？四进程不随系统自启。运行 start-scadia.ps1（本机已配开机自启：启动文件夹里的 SCADIA-开机自启.cmd，删除该文件即取消）。
