四、二次开发手把手教程（从零做一个新工程）

> 目标：读完能独立完成"新建视图 → 接导航 → 上真数据 → 写脚本 → 接相机 → 灌入验证 → 交付"的完整闭环。以矿区工程为参照，全部命令可复制。

0. 准备

  • 平台已按说明书第一章跑起来（http://127.0.0.1:1881，admin/123456）。
  • 会用两样东西：node 补丁脚本（改工程 JSON 用，工程是单行 JSON 不能手编）和无头探针（验证用，范本在交付机 _tools/ai-track/verify-*.cjs）。
  • 铁律先记三条：改完工程要 Ctrl+F5；脚本必须幂等；高频数据走静态文件不走 API。

1. 三分钟看懂工程结构

工程就是一个 JSON（project/_demos/demo-kuangqu.json），五个键决定一切：

键作用
devices数据源声明（如 AI 视频分析设备的轮询周期）
hmi.views每个画面一份 SVG（svgcontent）+ 元素事件表（items）
hmi.layout启动视图 start、导航 navigation、顶栏 header
scriptsCLIENT 脚本（每秒重跑，画面动效全靠它）
alarms/server报警与调度配置

一个视图 = svgcontent（画什么）+ items（谁能响应点击，onpage 切视图 / onOpenTab 开平台页）。

2. 第一个视图：复制外壳，改出自己的看板

  • 在 views 里复制一个现成视图（外壳含顶栏/导航/背景，别从白纸画）。
  • 改 svgcontent 里内容区的文字与图形；导航命中区是透明 rect（id=nav_xx），items 里同名的键给它绑事件。
  • 新加的纯装饰文字/图标必须加 pointer-events="none"，否则会盖住命中区吃掉点击（实测踩过）。
  • 每个视图的导航高亮（4 个蓝色元素：圆角框/左条/图标/粗体字）是写死的，克隆视图时记得把这组元素挪到本视图对应的行，否则高亮会停在别的页甚至悬空。

3. 接进导航

在 items 里给命中区绑事件（两种）：

"nav_my": { "id": "nav_my", "type": "svg-ext-shapes-rectangle",
  "property": { "events": [ { "type": "click", "action": "onpage", "actparam": "v_my_view" } ] } }
  • onpage = 演示视图内切换；onOpenTab = 打开平台页（/video /mes /ems /reports /users /editor），是当前标签页内跳转不是弹窗。
  • 想改默认落地页：hmi.layout.start。

4. 让画面活起来：三种数据途径

途径用法限流
静态文件 /_images/xx.json桥接器/追踪器高频写入，画面脚本 250ms~1s 读**不限**（首选）
平台 API（/api/alarms 等）低频状态全站 1000 次/5 分钟，页面内节流 5 秒起
设备绑定（devices + polling）平台原生 Tag 轮询按设备周期走

判断法：数据变化快于 1 秒 → 静态文件；秒级以下且量小 → API+节流。

5. 第一个 CLIENT 脚本

var MY_VER = 1;                                   // 改脚本必 bump，作废旧状态
var _s = (window.__my = window.__my || {});
if (_s.ver !== MY_VER) { _s.ver = MY_VER; _s.last = 0; }
// 本脚本每秒被平台重跑：这里做幂等的活
document.querySelectorAll('svg text').forEach(function (t) {
  if (t.textContent.trim() === '待填') { t.textContent = '真数据'; }
});
  • 禁用 setInterval（旧定时器会一直跑旧函数）；要周期任务就"挂平台心跳 + 时间戳节流"：

if (Date.now() - (_s.last||0) > 10000) { _s.last = Date.now(); doPoll(); }

  • 取登录 token：先 sessionStorage.currentUser（JSON.parse 后取 .token），localStorage 只是兜底。
  • 验证：写个无头探针（playwright-core），用 /api/signin 拿 token 后 addInitScript 注入 sessionStorage，再 goto /home 点导航断言 —— 范本 verify-aq.cjs。

6. 接第二台相机

  • 三配置：mjpeg-sources.json 加一路源；video-events.json / ai-tracker.json 各自指向新相机（口令别提交真实值）。
  • 相机端（海康 ISAPI）：PUT /ISAPI/Smart/FieldDetection/1 设检测区（归一化 ×1000），PUT /ISAPI/System/time 校时（必须整秒、不加补偿，ISAPI 不认毫秒）。
  • 围栏可视化三处必须一致：相机 FieldDetection 区域、video-events.json 的 fence.points、画面脚本读的 ai-fence.json（桥接器会按配置重发布）。
  • 桥接器对事件参数是热读的；改完 mjpeg-sources.json 要重启视频代理。

7. 灌入与验证（闭环）

// patch-my.cjs：node 改 JSON → POST 灌入 → 回读校验
const d = JSON.parse(fs.readFileSync(DEMO));
/* ...改 d... */
fs.writeFileSync(DEMO, JSON.stringify(d));
const r = await fetch(BASE + '/api/project', { method: 'POST',
  headers: { 'Content-Type': 'application/json', 'x-access-token': token }, body: fs.readFileSync(DEMO) });
  • 灌完必须回读服务端内容校验（429 会让"看似成功"其实没生效）。
  • 浏览器 Ctrl+F5，用无头探针断言（元素存在/可见/点击后 URL/计数变化），别靠肉眼。
  • 每批改动留备份 JSON（copy 一份带时间戳）。

8. 报警/计数/抓拍链路速查

相机事件 → 桥接器（防抖 debounceMs、字典翻译、计数落 video-events-count.json 与 _images/ai-counts.json）→ 平台 /api/ai/events → /api/alarms（查询页）+ 画面计数卡；同时 captureShot 经 ISAPI 抓图到 _images/alarm-shots/（index.json 登记，报警图片预览页读）。清零走 POST /api/ai/events/reset（需 admin）。

9. 常见坑（每条都实测踩过）

  • 改了没生效 → Ctrl+F5（热更新不达已开页面）。
  • setInterval 抓旧函数 → 禁用，挂平台心跳。
  • 正则按固定属性顺序写 → 克隆视图属性顺序不同会静默 0 命中；先抓含 id 的整个标签再改。
  • 正则字面量里出现 </text> → 斜杠截断正则；文本替换用字符串操作。
  • 新加 SVG 文字压住命中区 → pointer-events="none"。
  • 高频打 API → 429 全站连坐；走静态文件。
  • 相机时间带毫秒 → ISAPI 解析到错值；整秒写入。
  • Start-Process 路径带中文/空格 → ArgumentList 传单字符串并自己包引号。
  • 杀视频代理后 ffmpeg 成孤儿 → 重启代理前先数进程个数。
