五、常见问题

现象原因与处置
改了工程/脚本画面没变Ctrl+F5。平台热更新只对新打开的页面生效（实测：已开页面 42 秒内零变化）
视频窗黑看 http://127.0.0.1:1886/stats：有源有帧率=流正常（画面 10 秒内自愈）；无源=ffmpeg 未装或 RTSP 不通
画面像幻灯片（约 1 帧/秒）没有 ffmpeg，处于抓拍模式；装 ffmpeg（winget install ffmpeg）后重启
顶栏显示「YOLOv8 · 视频重连中/代理不可达」视频代理异常，按文案定位：重连中=代理在但流未建；不可达=1886 连不上
接口偶发 429平台全站限流 1000 次/5 分钟；高频数据一律走 /_images 静态文件
人体框不出现AI 追踪进程没起：看启动日志 / Python 依赖（pip install ultralytics opencv-python）
报警查询空表筛选条件太窄；默认已是「全部时间+未确认」
系统(用户)页空白游客无权限；用 admin 登录后 Ctrl+F5
计数清零提示需要权限需 admin 登录（token 在 sessionStorage.currentUser）
