17. 通知、密钥与插件

入口：菜单「系统」→ 通知 / API 密钥 / 插件

功能概述

这一组是平台的通知与扩展能力：通知中心记录系统事件与投递状态；API 密钥用于外部系统调用平台接口；插件页管理系统扩展。

逐步操作

  1. 通知页查看历史通知与投递结果（邮件需先在设置里配置 SMTP）。
  2. 密钥页新建 API 密钥，用于脚本或第三方系统调用平台 REST 接口。
  3. 插件页查看已安装的扩展与运行状态。
  4. 消息中心（/messages）用于查看报警消息流。

常见问题

  • 邮件没发出去？先确认 SMTP 配置（默认未配置）。
  • 密钥丢了怎么办？删除后重新生成。
  • 插件能自己装吗？由服务端目录决定，页面负责展示与启停。
